# Issue 10 Implementation Plan

**Goal:** 학교 사건·공통 면접과 국내/실리콘밸리 현장학습을 구현합니다.
**Spec:** GitHub #10, 사용자 제공 서버 기획서, 2026-11-19 추가 요청. 최신 요청이 기존 문서의 학사 일정 및 이전 커밋 개수보다 우선합니다.
